# Roadmap

Roughly in order. [games/fighters_megamix/PROGRESS.md](../games/fighters_megamix/PROGRESS.md) has the
detail.

1. The opening movie: make it play, and make skipping it with Start work without a BIOS image.
2. Hand play on the Mac: every mode, versus with two pads, sound.
3. Widescreen: the renderer's switch, then the HUD at the picture's edges (Fighting Vipers' way).
4. The fight rules as readable code, from Fighting Vipers' rewrites (round state machine, damage, input),
   then a training mode like Fighting Vipers' (dummy, input display, frame data, hit view, reset point).
5. Linux, SteamOS and Windows builds (the toolkit's release scripts).
